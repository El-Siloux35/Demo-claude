GSAP SplitText

Quatorze animations de texte, et leur nom.

Chaque carte porte le nom anglais de l'effet. Ce nom n'est pas décoratif : c'est le terme que les développeurs emploient entre eux, celui que la documentation utilise, et celui qu'il faut écrire pour obtenir l'effet quand on demande le code à une IA. « Fais un line mask reveal sur le titre » donne le bon résultat du premier coup ; « fais apparaître le titre joliment » ne le donne jamais.

Prompt utilisé

Construis une page HTML autonome qui présente, sous forme de galerie, quatorze animations de texte réalisées avec GSAP et son plugin SplitText.

Cette page s'adresse à des étudiants. L'objectif n'est pas d'expliquer le code, mais de leur donner le vocabulaire : chaque carte porte le nom anglais de l'effet, celui qui figure dans la documentation et qu'il faut écrire pour obtenir cet effet quand on demande du code à une IA. N'affiche donc aucun extrait de code, seulement l'animation, son nom, et une phrase disant à quoi elle sert.

Couvre les trois familles : les révélations par masque (ligne, mot), les ordres de décalage (du début, du centre, au hasard, machine à écrire), et les effets par caractère (flou, échelle, rotation 3D, vague, élan élastique).

Chaque carte est un bouton : un clic rejoue son animation, et le clavier y accède. Au chargement, les cartes se déclenchent en cascade.

Charge GSAP et SplitText en version 3.13 ou supérieure, où le plugin est devenu gratuit. Respecte prefers-reduced-motion en remplaçant les déplacements par de simples fondus.
