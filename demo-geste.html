Démo : interface gestuelle par caméra

Aucun bouton. Seulement le geste, suivi par la caméra.

Pincez le pouce et l'index en l'air pour attraper un fragment d'histoire, déplacez la main pour le glisser, ouvrez les doigts pour le lâcher. Votre webcam suit votre main en temps réel : aucune image n'est envoyée où que ce soit, tout reste dans le navigateur.

⚠️ Gorilla arm effect : gardez le coude proche du corps, ne tendez pas le bras en l'air trop longtemps. Une bonne interface gestuelle fatigue le moins possible.

chargement du suivi de main…

Chargement du modèle de suivi de main (MediaPipe) : nécessite une connexion internet la première fois, puis l'autorisation de la caméra.

Prompt utilisé

Construis une page HTML autonome où on manipule des éléments à la main devant la webcam, sans souris ni clavier.

Utilise MediaPipe Tasks Vision (HandLandmarker, le modèle de suivi de main de Google) pour détecter les points de repère de la main. Quand le pouce et l'index se rapprochent, considère la main en pincement et attache l'élément visé au curseur ; quand ils s'écartent, dépose-le. Prévois deux seuils différents pour la fermeture et l'ouverture, sinon le pincement clignote.

Tout se calcule dans le navigateur, aucune image n'est envoyée. Gère proprement le refus d'accès à la caméra.
